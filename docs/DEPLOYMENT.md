# CricAnalyser Deployment Guide

## Demonstration mode

The web dashboard is deployable independently of the local Hadoop/Spark stack.

- Local mode: the API reads `data/processed/` generated by Spark.
- Cloud demo mode: the API falls back to `data/demo/processed/`, a small precomputed snapshot generated from the same analytical pipeline.
- Hadoop HDFS and Spark remain the actual Big Data processing layer and are demonstrated locally on Windows.

This separation is intentional: a normal Vercel deployment should not be presented as if Hadoop or Spark were running inside the web hosting environment.

## Vercel

1. Open Vercel and import the GitHub repository `kabugadeShivam/CricAnalyser`.
2. Framework: Next.js.
3. Root directory: repository root.
4. Build command: `npm run build`.
5. Install command: `npm install`.
6. No environment variables are required for the dashboard demo.
7. Deploy.

The deployed dashboard will automatically use the committed demo snapshot unless Spark outputs are present in the deployment filesystem.

## Local demonstration

PowerShell:

```powershell
git clone https://github.com/kabugadeShivam/CricAnalyser.git
cd CricAnalyser

npm install
npm run build
npm run dev
```

Open `http://localhost:3000`.

For the complete Big Data demonstration, run the Spark pipeline first:

```powershell
py -m venv .venv
.\\.venv\\Scripts\\Activate.ps1
pip install -r requirements.txt
python src\\data_cleaning\\validate_raw.py
python src\\data_cleaning\\clean_data.py
spark-submit spark\\ipl_pipeline.py
npm run dev
```

## Presentation flow

1. Explain the architecture: raw data → HDFS → Spark → analytics → dashboard.
2. Show the HDFS folders and uploaded raw data.
3. Run/describe the PySpark cleaning stage.
4. Show Spark-generated analytical outputs.
5. Open the dashboard.
6. Navigate through Overview, Batting, Bowling, Teams, Venues and Insights.
7. Explain that the cloud dashboard uses the same processed schema through a demo snapshot.
8. Show the repository and automated Next.js build workflow.

## Important data note

The dataset is an IPL-style educational/synthetic dataset used for demonstrating Big Data engineering and analytics. Generated values should not be presented as verified official IPL historical statistics.
