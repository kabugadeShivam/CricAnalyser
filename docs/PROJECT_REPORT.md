# Project Report Structure

## Title
**Big Data Analytics for IPL Match and Player Performance Using Hadoop and Apache Spark**

## 1. Abstract
Explain that the project processes match-level and ball-by-ball IPL-style data using HDFS and Spark, performs distributed transformations and produces analytical datasets for Power BI.

## 2. Problem Statement
Historical ball-by-ball cricket data is difficult to analyze manually across many seasons. A distributed processing architecture is used to clean, aggregate and analyze the data efficiently.

## 3. Objectives
1. Store large cricket datasets using HDFS.
2. Clean and transform data using PySpark.
3. Use Spark DataFrames and Spark SQL for distributed analytics.
4. Generate batting, bowling, team, venue, phase and toss insights.
5. Visualize processed results in Power BI.
6. Demonstrate an optional ML extension.

## 4. Technology Stack
| Layer | Technology |
|---|---|
| Storage | Hadoop HDFS |
| Processing | Apache Spark |
| Language | Python / PySpark |
| Query | Spark SQL |
| Visualization | Power BI |
| Optional ML | Spark MLlib |
| Development | VS Code / PowerShell |

## 5. System Architecture
Raw CSV → HDFS → Spark → Cleaning → Parquet → Analytics → CSV → Power BI.

## 6. Dataset
Two files are used: match-level `matches.csv` and ball-level `deliveries.csv`. The project dataset is an **IPL-style educational/synthetic dataset** unless independently verified against official historical records.

Discuss:

- run consistency

Explain distributed Spark transformations:

- join

Explain why Parquet is used for cleaned data: columnar storage and efficient analytical reads.

## 9. Analytics
### Batting
Runs, boundaries, matches played, consistency.

### Bowling
Wickets, runs conceded, overs, economy.

### Teams
Season-wise runs, matches and wickets.

### Phases
Powerplay: overs 1–6; Middle: overs 7–15; Death: overs 16–20.

### Venue
Runs, matches and wickets by venue.

### Toss
Toss decision and relationship with match winner.

## 10. Power BI
Four dashboard pages:
1. Overview
2. Batting
3. Bowling & Teams
4. Matches & Venues

## 11. Optional ML
First-innings score prediction using score, wickets, overs, season and venue.
