# Power BI Dashboard

Import the CSV part file from each folder under `data/processed/`.

## Page 1 — IPL Overview
Cards: total matches, total runs, total wickets, seasons.
Charts: total runs by season and runs per match by season.

## Page 2 — Batting Analysis
- Top 10 batters by runs
- Runs per match
- Fours and sixes
- 30+, 50+, 100+ scores
- Consistency score

## Page 3 — Bowling & Team Analysis
- Top wicket takers
- Wickets vs economy
- Team runs by season
- Runs per match by team

## Page 4 — Match & Venue Analysis
- Toss winner vs match winner
- Toss decision distribution
- Runs and matches by venue
- Match winner and margin table

## Phase analysis
Use `phase_analysis` for Powerplay, Middle and Death overs.

**Data note:** the dataset is treated as IPL-style educational/synthetic data unless independently verified against official historical IPL records. Do not present generated values as official IPL statistics.
